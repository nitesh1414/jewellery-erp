# Jewellery ERP — Desktop Edition (Tauri 2)

This is the desktop packaging of the Jewellery ERP web application.
The same React/Vite frontend is embedded in a native window using Tauri 2, providing direct OS access for hardware like thermal printers, barcode scanners, and the cash drawer.

## Quick start

```bash
# Install Rust (one-time)
curl https://sh.rustup.rs -sSf | sh -s -- -y
source $HOME/.cargo/env

# Install dependencies
npm install

# Generate icons
npm run tauri:icon -- ./my-logo.png

# Run in dev mode
npm run tauri:dev

# Build production executable
npm run tauri:build
```

## Production builds

| Build target | How |
|--------------|-----|
| Windows `.exe` `.msi` | `npm run tauri:build:windows` |
| Linux `.AppImage` `.deb` `.rpm` | `npm run tauri:build:linux` |
| macOS `.dmg` (Apple Silicon) | `npm run tauri:build:mac` |
| macOS `.dmg` (Intel) | `npx tauri build --target x86_64-apple-darwin` |
| Linux ARM64 | `npx tauri build --target aarch64-unknown-linux-gnu` |

For cross-platform CI builds, see `.github/workflows/build-desktop.yml`.

## Hardware integration

The Tauri backend exposes commands the frontend uses:

### Thermal printer (ESC/POS)
```ts
import { invoke } from '@tauri-apps/api/core';
await invoke('print_thermal_receipt', {
  payload: {
    shop_name: '...',
    items: [...],
    // ...
  },
});
```

### Barcode scanner (USB / serial)
```ts
const ports = await invoke('list_serial_ports');
```

### Cash drawer
```ts
await invoke('print_thermal_receipt', { payload, options: { open_drawer: true } });
```

### Offline mode (synced when online)
```ts
const status = await invoke('get_offline_status');
await invoke('cache_bill_for_offline', { payload: pendingTx });
await invoke('sync_pending_transactions', { serverUrl: 'http://...' });
```

## Folder layout

```
desktop/
├── src/                    React/Vite SPA (shared with web frontend)
├── src-tauri/              Rust backend
│   ├── Cargo.toml          Rust dependencies
│   ├── tauri.conf.json     Tauri config (icons, bundle settings, plugins)
│   ├── capabilities/       Tauri 2 permission model
│   ├── icons/              App icons (auto-generated by `tauri icon`)
│   └── src/
│       ├── main.rs         Entry point
│       ├── lib.rs          Tauri setup + plugin registration
│       ├── state.rs        AppState types
│       ├── commands.rs     #[tauri::command] handlers
│       ├── printer.rs      ESC/POS thermal printer
│       └── offline.rs      Local SQLite + pending queue
├── vite.config.ts          Vite config (Tauri-aware)
├── package.json
└── index.html              HTML entry
```

## Notes

- The frontend in `src/` mirrors the SPA in `packages/frontend/src/`. Kept intentionally lightweight — desktop-specific logic lives in the Tauri backend (Rust).
- For local development, the app opens in a separate window from the backend. Backend at `http://localhost:3001` must be running.
- See `docs/DESKTOP.md` for cross-platform build instructions and CI configuration.
